# Этап 1 — Миграция на PostgreSQL

## Что было сделано

### 1. Проектирование базы данных PostgreSQL
Создана полная схема реляционной базы данных, которая заменит текущую Couchbase.

**Что входит:**
- Таблицы для всех модулей: товары, склады, накладные, валюты, контрагенты, кассы, пользователи
- Связи между таблицами (foreign keys) с правилами каскадного удаления
- Проверки целостности данных (например, делитель не может быть равен нулю)
- Все суммы и цены хранятся с точностью до 4 знаков после запятой (NUMERIC) — без потери точности

📄 Файл: `Payhas.Binyat.Data.Postgres/Scripts/001_create_database.sql`

---

### 2. Программный слой доступа к данным (EF Core)
Создан новый проект `Payhas.Binyat.Data.Postgres`, который подключается к PostgreSQL и заменяет текущий слой Couchbase.

**Что входит:**
- 18 моделей данных (Entities), по одной на каждую таблицу
- Центральный класс `PayhasDbContext` — точка входа для всех операций с БД
- Настройка подключения через Dependency Injection (одна строчка для подключения)
- Настройки целевого фреймворка: .NET 8

📂 Папка: `Payhas.Binyat.Data.Postgres/Entities/`

---

### 3. Быстрый поиск товаров
Реализован новый поисковый движок, который заменяет медленный полнотекстовый поиск Couchbase.

**Что изменилось:**

| | Было (Couchbase) | Стало (PostgreSQL) |
|---|---|---|
| Количество запросов к БД | 3 последовательных | 1 запрос |
| Скорость | 200–500 мс | Цель: менее 100 мс |
| Поиск с опечатками | Нет | Да (нечёткий поиск) |
| Поиск по штрих-коду | Медленный | Мгновенный (точное совпадение) |

📂 Папка: `Payhas.Binyat.Data.Postgres/Repositories/`

---

### 4. Система локализации (многоязычность)
Создан движок локализации для поддержки русского и туркменского языков.

**Что входит:**
- Русская локализация: 100+ текстов интерфейса
- Туркменская локализация: 100+ текстов интерфейса
- Менеджер переключения языков в реальном времени
- Поддержка формата дат и чисел для каждого языка

📂 Папка: `Payhas.Binyat.Core/Localization/`
